# 🚴 DeliveryPro – Food Delivery Platform

A modern, responsive **Food Delivery Management Platform** built with HTML, CSS, and JavaScript. DeliveryPro provides a complete interface for managing orders, restaurants, delivery partners, customers, payments, tracking, reviews, reports, and delivery routes.

---

## 📌 Overview

**DeliveryPro** is a role-based food delivery management application designed to simulate the workflow of a modern food delivery service.

### 👥 User Roles

- 👨‍💼 Admin
- 🍽️ Restaurant
- 🚴 Delivery Partner
- 👤 Customer

Each role has access to features relevant to its responsibilities.

---

## ✨ Features

### 📊 Dashboard
- Total orders overview
- Revenue statistics
- Active deliveries
- Delivered orders
- Available delivery partners
- Average ratings
- Order status charts
- Restaurant revenue charts

### 📦 Order Management
